# HealthGuard AI — API

Мониторинг здоровья астронавтов. **Не ставит диагнозов** — сообщает об отклонениях от личной нормы человека.

* Интерактивная документация со всеми запросами (можно пробовать в браузере): **`<адрес>/docs`**
* Проверка, что сервер жив: `GET <адрес>/health` → `{"status": "ok"}`

| Адрес | Вход | Выход |
|---|---|---|
| `POST /heart` | ЭКГ (мВ), частота `fs`; ≥ 5 мин (первые 300 сокращений — личная калибровка) | пульс, RMSSD, % внеочередных сокращений, типы сокращений, качество сигнала |
| `POST /sleep/headband` | ЭЭГ повязки (Fpz-Cz) + EOG, 100 Гц, вся ночь | гипнограмма W/Light/Deep/REM по 30 с, время и эффективность сна |
| `POST /sleep/wrist` | ускорение браслета (g) + пульс | сон/бодрствование, время и эффективность сна |
| `POST /activity/microgravity` | акселерометр (g) + гироскоп (рад/с), 50 Гц, датчик на поясе | ходьба / вверх / вниз / покой |
| `POST /activity/training` | браслет + грудной датчик (м/с², рад/с) + пульс, 100 Гц | бег, велотренажёр, прыжки, ходьба, покой, бытовая |
| `POST /mental` | грудной датчик (700 Гц) + браслет; первые 10 мин — спокойствие | вероятность стресса по минутам |
| `POST /radiation` | мощность дозы (мкГр/ч) + широта, долгота, L | накопленная доза, прогноз, тревоги солнечных событий |
| `POST /engine` | дневные показатели (≥ 15 дней) | уровень Normal/Attention/Warning/Critical + текст уведомления |

## Пример (Python)

```python
import requests
URL = "https://<адрес>"
days = [dict(resting_hr=62, rmssd=45, ectopic_pct=0.2, sleep_h=7.2, sleep_eff=90, active_min=60,
             rad_mSv=0.5, stress_frac=0.1, pvt_rt=260) for _ in range(20)]
days[-1].update(sleep_h=4.5, resting_hr=75)
r = requests.post(f"{URL}/engine", json={"days": days}).json()
print(r["levels"][-1]); print(r["days"][-1]["notification"])
```

Целая ночь ЭЭГ — это миллионы чисел; для `/sleep/headband` их удобнее слать компактно:

```python
import base64, numpy as np
b64 = lambda x: base64.b64encode(np.asarray(x, "<f4").tobytes()).decode()
requests.post(f"{URL}/sleep/headband", json={"eeg_fpz_cz_b64": b64(eeg), "eog_b64": b64(eog), "fs": 100, "units": "uV"})
```

## Запуск у себя (без интернета)

```
docker build -t healthguard . && docker run -p 8080:8080 healthguard
```
или Python 3.8: `pip install -r requirements.txt && uvicorn app:app --port 8080` → http://localhost:8080/docs
